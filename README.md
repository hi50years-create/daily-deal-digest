# 매일 할인정보 자료 수집 봇 (무료 버전)

매일 정해진 시간에 뽐뿌 핫딜 게시판에서 생활 할인정보를 찾아서,
정리된 목록을 이메일로 보내주는 자동화 파이프라인입니다.

**💰 비용: 0원.** API 호출 없이 순수 스크래핑 + 이메일 발송만 해요.

**⚠️ 완성된 블로그 글이 아니라 "재료 목록"이 옵니다.** 원문 제목 그대로
정리해서 보내드리니, 그대로 블로그에 올리면 안 되고 다듬어서 써야 해요.
아침에 메일 받으면 통째로 복사해서 Claude 채팅에 붙여넣고
"이 할인정보로 블로그 글 써줘" 하면 바로 완성본을 받을 수 있어요
(지금 쓰시는 구독 안에 포함, 별도 비용 없음).

## 준비물 (딱 한 번만 설정)

1. **GitHub 저장소** — 이 폴더 전체를 업로드
2. **Gmail 앱 비밀번호** — 구글 계정 설정 > 보안 > 2단계 인증 켠 뒤 "앱 비밀번호" 생성
3. **받을 이메일 주소**

## GitHub Secrets 등록

저장소 Settings > Secrets and variables > Actions > New repository secret 에서 3개 등록:

| Secret 이름 | 값 |
|---|---|
| `SMTP_USER` | 발신용 Gmail 주소 |
| `SMTP_PASS` | 앱 비밀번호 (일반 비밀번호 아님!) |
| `RECIPIENT_EMAIL` | 받으실 이메일 주소 |

## 테스트 방법

1. 저장소 Actions 탭 > "매일 할인정보 초안 메일 발송" 워크플로우 선택
2. "Run workflow" 버튼으로 수동 실행
3. 몇 분 뒤 메일함 확인

## 발행 시간 바꾸기

`.github/workflows/daily-deals.yml`의 `cron: '0 23 * * *'` 부분을 수정하세요.
GitHub Actions cron은 UTC 기준이라 한국시간 -9시간으로 계산해야 해요.
(예: 한국시간 오전 7시에 받고 싶으면 `0 22 * * *`)

## 셀렉터가 깨졌을 때

뽐뿌 사이트 디자인이 바뀌면 `scripts/fetch_deals.py`의 CSS 선택자
(`tr.baseList`, `a.baseList-title`)가 안 맞을 수 있어요. 그럴 땐
"뽐뿌 스크래핑 안 돼" 하고 캡처 보내주시면 다시 봐드릴게요.

## 필터 키워드 조정

`scripts/fetch_deals.py`의 `LIFESTYLE_KEYWORDS` 리스트에 원하는 브랜드/카테고리를
추가하거나 빼면 필터링 범위를 바꿀 수 있어요.

## 나중에 완전 자동 글쓰기로 업그레이드하고 싶다면

`scripts/build_draft.py`를 Claude API 호출 버전으로 바꾸면 돼요
(월 1달러 미만 예상). 원하시면 그때 다시 만들어드릴게요.
